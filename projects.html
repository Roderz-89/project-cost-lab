How to use this projects catalogue

This catalogue brings together the project types used by the Project Cost Lab calculator: loft conversions, extensions, boilers, kitchens, windows and other common UK home works. Use the filters to narrow the list, then select a project name to open it in the calculator with a starting point.

Each compiled mid is a baseline before the calculator applies size, specification, region, access, VAT display and contingency choices. It is useful for comparing project shapes, not for predicting the exact cost of one property. For the assumptions behind particular categories, see the loft guide, extension guide, boiler guide, VAT guide and region and access guide.

Projects catalogue FAQ

How should I use a row?

Start with a project that resembles the work you are considering. Open its link to load the calculator, check the default size and then change the quantity, specification and other assumptions to match your early brief.

Why is the mid not a quote?

The mid is the centre of a planning band compiled for a typical starting scenario. Survey findings, design, labour availability, materials, site constraints and the final brief can move a real price substantially, so it is not a tender or a promise.

What do lump, per m², per run and per unit mean?

A lump item is shown as a whole-job starting mid. Area, run and unit items scale by the default quantity shown in the table, such as floor area, metres or individual units. The calculator lets you replace that default where the project allows it.

Where do region, access and specification choices fit?

They are factors applied in the calculator after the catalogue baseline. Use them to describe the broad location, how easy the site is to reach and the level of finish or equipment you have in mind; they are planning adjustments, not a site survey.

What does the VAT display do?

The VAT control changes how the estimate is displayed for planning. It does not decide whether a job, customer or supplier should be charged VAT, and it is not a tax ruling. Confirm the treatment with the relevant contractor or adviser.

When should I get real quotes?

Once the scope and access are clear, obtain written, itemised quotes from suitable local firms. For structural, legal or compliance questions, use the appropriately qualified professional; keep this catalogue as an early budgeting aid.
